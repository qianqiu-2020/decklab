    需要 root 密码登录？
    
已有普通用户可直接通过上方表单连接。以下步骤适用于 Ubuntu / Debian，需要板端 sudo 权限；命令仅复制到剪贴板，由你在串口中自行执行。

    
请分步执行，完成当前命令的密码输入并返回 shell 后，再执行下一步。不要将整份指引一次性粘贴到串口。

    
1. 设置 root 密码

    
sudo 提示时输入当前普通用户密码；随后按提示输入两次你选择的 root 新密码。

    
sudo passwd root

    
2. 编辑 SSH 服务配置

    
sudoedit /etc/ssh/sshd_config

    
将以下两项放在配置文件开头、Include 之前，然后保存退出。

    
配置片段

    
PermitRootLogin yes
PasswordAuthentication yes

    
3. 检查并重启 SSH

    
sudo /usr/sbin/sshd -t && sudo systemctl restart ssh

    
4. 确认生效配置

    
sudo /usr/sbin/sshd -T | grep -E '^(permitrootlogin|passwordauthentication) '

    
确认两项均为 yes 后，在上方填写 root 和刚设置的密码重试。

      首次安装：使用独立 Python 环境
      
      先下载 DeckLab 源码，并将下方源码目录替换为实际路径。最后一行显示应填写的可执行文件路径。
      
      
      Linux / macOS
      python3 -m venv "$HOME/.local/share/decklab-mcp"
"$HOME/.local/share/decklab-mcp/bin/python" -m pip install /path/to/decklab
echo "$HOME/.local/share/decklab-mcp/bin/seriald-mcp"
      
      
      Windows PowerShell
      py -3 -m venv "$env:LOCALAPPDATA\decklab-mcp"
& "$env:LOCALAPPDATA\decklab-mcp\Scripts\python.exe" -m pip install C:\path\to\decklab
Join-Path $env:LOCALAPPDATA 'decklab-mcp\Scripts\seriald-mcp.exe'
