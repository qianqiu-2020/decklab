# Inno Setup installer translation

`ChineseSimplified.isl` is copied from Inno Setup **6.7.3**:
https://github.com/jrsoftware/issrc/blob/is-6_7_3/Files/Languages/Unofficial/ChineseSimplified.isl

Only line endings and trailing whitespace are normalized.

The file declares compatibility with Inno Setup 6.5.0+. Its translation author
credits are retained in the header. The upstream license is included in
`LICENSE.txt`. Keeping this resource in the repository avoids relying on the
optional language files present in a builder's compiler installation.
