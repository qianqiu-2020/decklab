# 串口与 SSH

串口是开发板的本地控制台。控制机持有串口并持续保存收到的字节，网页可以稍后接入。SSH 是独立的网络会话，由控制机用该板的地址和凭据连接，可以在同一设备下打开多个会话。

## 第一次连接

接好串口线，在设备列表中打开对应端口。若仍显示「待识别」，先检查波特率和启动输出，再按[设备身份](device-identity.md)中的识别方法核对板卡。自动识别需要从板上获得身份信息，USB 转串口适配器自身的序列号只能说明控制机识别了哪条线。

需要登录时，在串口终端使用镜像对应的账号。要使用 SSH，先确认系统已联网并运行 SSH 服务。Debian 桌面镜像可能需要完成引导并创建普通用户。SSH 设置保存在所选板卡下，在该页可打开新的会话。

## 多人操作同一板卡

浏览器终端分享同一串口的屏幕状态和日志。发命令前先检查设备标题及当前输入控制状态。交互命令、终端尺寸同步，以及临时发送的探测命令分别进入控制机的终端协调逻辑。需要独占输入的任务会在任务页显示占用。[终端协调](console-transactions.md)

## 日志、搜索与故障判断

「当前终端」只搜索当前会话保留的画面。「历史日志」可按启动记录或日期查找采集归档。若实时画面中没有某段输出，先查对应设备的原始归档，核对当时有无控制机重启、串口断开和写盘错误。[日志与归档](../operations/log-operations.md)

SSH 连接问题先检查目标地址、账号、凭据和目标侧 SSH 服务。网络连接断开后可回到串口处理，串口采集仍依赖控制机与板卡之间的硬件连接。
