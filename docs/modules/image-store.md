# 镜像商店

左侧“镜像商店”可以浏览和下载镜像。刷机工作区进入商店后，点击“下载并使用”会在下载完成时直接带回当前选择；不用切到“已下载”再选一次。分区行的“从商店选择文件”只显示可直接写入的文件，选择后自动绑定并勾选该行。关闭选择窗口、切换设备或另选内容后，旧下载只保存到缓存，不会覆盖新选择。下载和删除仅操作控制机缓存，刷写仍须选择板型、分区、预览范围并确认。

- 公开源：https://archive.spacemit.com/image/
- 组织源默认关闭。在「系统配置 → 组织镜像」填写 Nexus 根地址，例如 `https://repo.example.test/`。应用后控制机使用 `/service/rest/repository/browse/image/` 浏览，从 `/repository/image/` 下载文件。Nexus 的下载根目录本身可能返回 404，文件仍可下载。已有自定义浏览和下载地址可继续使用。

选择 K1/K3 后按 OS 标签页浏览，在“版本”和“Daily”间切换；版本号按数字倒序，Daily 按日期倒序，默认只列最新批次。版本／日期下拉框可切换历史批次，再按 LXQt、GNOME、Minimal、Firmware 等变体筛选；UEFI 等差异仍保留在完整文件名中。搜索框只筛选当前版本。多层版本目录保留“内容目录”选择；不规则目录仍可按原路径浏览。仅读取选中的分支，不遍历全部历史。目录元数据缓存 60 秒，“刷新”强制重新读取。列表保留镜像包（tar.gz、tgz、tar、zip）和分区载荷（itb、ext4、bin），过滤 img／raw 及其压缩文件、ISO、校验文件和刷机脚本压缩包。既有缓存中的不支持格式仍可删除，但不能选择用于刷写。扩展名筛选不代表已验证板型兼容性，当前完整包的内置 RAM 材料支持 K3。

进入 cloud 等子目录时继续保留 OS、版本／Daily 和日期选择，只读取选中的目录；“内容目录”可切换子目录，文件与子目录并列时可选择“当前目录”返回该层文件，不退回旧路径布局。

点击“下载到控制机”后复用现有异步下载任务、磁盘配额及 SHA-256 校验。可取消下载；关闭窗口或刷新页面不会重新提交任务。“已下载”重新读取原下载任务和共享缓存，可选择或确认删除镜像。正在被任务使用的文件不能删除。网络中断导致提交结果未知时，先到“已下载”核对原任务，不自动重试。

镜像保存在 `DECKLAB_BASE` 下既有传输缓存中，受 [传输文件配额和保留策略](file-transfer.md) 管理，默认就绪文件保留 7 天。控制机空间不足时，可把数据目录放到外部磁盘并调整配额。浏览商店无需占用板卡；下载也不执行复位或写存储。

用户提供 URL 的下载入口继续保留。商店、缓存列表和 URL 下载仅供网页操作者使用，设备 Agent 授权不能导入任意镜像或读取共享镜像缓存。

组织镜像的配置地址支持自签证书。公开镜像和其他 HTTPS 下载地址仍校验证书。URL 极速刷机使用组织仓库的直接下载链接，遇到重定向会停止。

完整固件包属于“镜像来源”，不作为单分区的原始文件列在替换文件列表里。选择包作为来源后，所选分区显示“匹配包内分区”；执行器按包内分区映射取载荷，并在预览时核对现场布局与容量。缺少对应分区会报错，不通过文件名猜测，也不会把整包直接写进一个分区。一个单独文件只在目标明确时自动绑定，不会自动复制到多个所选分区。
