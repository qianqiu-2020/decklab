# 镜像商店

左侧“镜像商店”可以浏览和下载镜像。刷机工作区进入商店后，点击“下载并使用”会在下载完成时直接带回当前选择；不用切到“已下载”再选一次。分区行的“从商店选择文件”只显示可直接写入的文件，选择后自动绑定并勾选该行。关闭选择窗口、切换设备或另选内容后，旧下载只保存到缓存，不会覆盖新选择。下载和删除仅操作控制机缓存，刷写仍须选择板型、分区、预览范围并确认。

- 公开源：https://archive.spacemit.com/image/
- 内部源：https://nexus.bianbu.xyz/service/rest/repository/browse/image/ 。由控制机访问，需具备内网连接；文件使用 Nexus 的实际下载地址。

按 K1/K3 进入目录，搜索框筛选当前目录的名称。目录元数据缓存 60 秒，“刷新”强制重新读取。列表展示镜像包（tar.gz、tgz、tar、zip）、磁盘镜像（img、raw 及 gzip）和分区载荷（itb、ext4、bin），排除刷机脚本压缩包。扩展名筛选不代表已验证板型兼容性，当前完整包的内置 RAM 材料支持 K3。

点击“下载到控制机”后复用现有异步下载任务、磁盘配额及 SHA-256 校验。可取消下载；关闭窗口或刷新页面不会重新提交任务。“已下载”重新读取原下载任务和共享缓存，可选择或确认删除镜像。正在被任务使用的文件不能删除。网络中断导致提交结果未知时，先到“已下载”核对原任务，不自动重试。

镜像保存在 `SERIALD_BASE` 下既有传输缓存中，受 [传输文件配额和保留策略](TRANSFER_ARTIFACTS.md) 管理，默认就绪文件保留 7 天。控制机空间不足时，可把数据目录放到外部磁盘并调整配额。浏览商店无需占用板卡；下载也不执行复位或写存储。

用户提供 URL 的下载入口继续保留。商店、缓存列表和 URL 下载仅供网页操作者使用，设备 Agent 授权不能导入任意镜像或读取共享镜像缓存。

Windows 包内的 HTTPS 使用系统原生证书链校验。内部 Nexus 使用组织 CA，非域电脑需由管理员按组织规范配置受信任证书；证书错误会明确提示，不自动导入根证书或跳过验证。

完整固件包属于“镜像来源”，不作为单分区的原始文件列在替换文件列表里。选择包作为来源后，所选分区显示“匹配包内分区”；执行器按包内分区映射取载荷，并在预览时核对现场布局与容量。缺少对应分区会报错，不通过文件名猜测，也不会把整包直接写进一个分区。一个单独文件只在目标明确时自动绑定，不会自动复制到多个所选分区。
