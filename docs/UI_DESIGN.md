# 界面设计约定

seriald 是 OS 开发者的串口 / SSH 工作台。终端占主要空间，设备切换、日志与传输围绕终端组织。保留原生 HTML、CSS 和 xterm，不引入需要联网加载的前端框架。

## 本次审计与调整

- 原字体声明包含未打包的 Inter / IBM Plex，实际字体因主机而异。改为本机界面字体和统一的等宽字体候选；中文保留系统回退。
- 临时手绘图标改为 Tabler Icons 的官方 outline 图标。文字标签保留，图标辅助定位，不承担独立解释。
- 首页三个统计卡片合并为紧凑统计行，把空间留给设备列表。
- 移除会话类型的装饰圆点；在线、离线、待识别状态继续使用明确文字和状态色。
- 控件跟随系统明暗偏好。终端保持深色 ANSI 配色，避免切换网页主题影响启动菜单、选择高亮和命令分割。

## 后续实现原则

视觉参数：`DESIGN_VARIANCE: 3`、`MOTION_INTENSITY: 2`、`VISUAL_DENSITY: 8`。强调清晰层级、短距离操作和少量状态反馈。

颜色使用 `static/app.css` 的语义变量。蓝色用于可操作与选中状态；绿、红、琥珀色仅表达设备状态、危险操作或差异。普通控件圆角约 6–8 px，工作区约 12 px，浮层约 14–16 px。

不要修改 xterm 的滚动层以追求统一外观；必须保留可点击滚动条、底行空间及全屏程序行为。查看归档后保留列表，方便连续切换。传输浮层允许移动，不遮断无关设备与 SSH 的操作。

## 图标来源

`static/icons.svg` 提取自 `@tabler/icons@3.35.0`，使用项目现有 `i-*` 别名；许可证见 `static/icons-LICENSE.txt`。来源：https://github.com/tabler/tabler-icons。

取回同版本原文件：`npm pack @tabler/icons@3.35.0`。仅更新所需图标，不将完整图标库加入包。正常构建与运行无需 npm 或公网连接。

## 验证范围

明暗主题分别检查 1600×1000 桌面与 620×900 窄屏布局；检查首页、归档侧栏和文件传输浮层。主要文字、操作色和状态色的实测对比度均达到 4.5:1；键盘焦点覆盖按钮、输入、选择框、链接和维护菜单。低运动偏好禁用控件过渡。

`design-taste-frontend` 的营销页英雄图、摄影、动画与展示卡片规则不适用于实时终端工作台，不应为套用这些规则添加装饰或改变操作路径。
